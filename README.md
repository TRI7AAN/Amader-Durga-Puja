# Amader Durga Puja

By Debasmita Das — elegant Kolkata pandal hopping trails for North & South Kolkata with live walking routes, auto shortcuts and step-by-step guides. Shubho Sharodiya!

## Files

- `index.html` — Main landing page: Kolkata Pandal Hopping Trails
- `north_kolkata_durga_puja_pandal_hopping_route_map_by_DDas.html` — North Kolkata Route & Live Guide
- `south_kolkata_durga_puja_pandal_hopping_route_map_by_DDas.html` — South Kolkata Route & Live Guide
- `south_kolkata_pandal_hopping_plan_2_0_route_map.html` — South Kolkata Plan 2.0 Trail & Live Guide

## Usage

Open `index.html` in a browser, or serve the folder statically:

```bash
npx serve .
# or
python -m http.server
```

No build step required. Static HTML + Tailwind CDN.
